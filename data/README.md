# Data

All files are generated by `quoteline` commands and committed so CI and the public demo run offline.

| File | Made by | Content | Licence of contents |
|---|---|---|---|
| `bandit/targets.jsonl` | `dataset-targets` | Training target papers (Hugging Face daily papers, 46 dates 2023–2026) | arXiv metadata, CC0 |
| `bandit/questions.jsonl` | `dataset-questions` | One generated question per target (`qid`, `question`, `target`) | Generated |
| `bandit/arms.jsonl` | `dataset-arms` | Top-5 arXiv IDs per arm for each training question | IDs only |
| `bandit/golden_arms.jsonl` | `dataset-arms --golden` | Top-5 arXiv IDs per arm for each golden question | IDs only |
| `bandit/golden_papers.jsonl` | `dataset-arms --golden` | Canonical metadata of every golden result | arXiv metadata, CC0 |
| `bandit/judgments.jsonl` | `dataset-judge` | LLM relevance judgment per (golden question, paper) | Generated |
| `bandit/report.json`, `policy.json` | `bandit` | Replay evaluation and the fitted LinUCB policy | Generated |
| `retrieval.jsonl` | `record-demos` | Retrieval results of the recorded demo runs | arXiv metadata, CC0 |

Search results were found through arXiv, Hugging Face and OpenAlex (CC0); displayed text is always arXiv metadata.
